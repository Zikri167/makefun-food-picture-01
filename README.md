# A bowl of ramen

The picture shows a warmly lit bowl of ramen, with glossy noodles lifted
above the broth, soft eggs with golden centers, and fresh green onions.

The Node program beside the image checks the JPEG signature, size, frame
type, dimensions, and closing marker before copying the original bytes to
the requested output directory. It prints the destination, image details,
and SHA-256 digest so each run can be checked.
